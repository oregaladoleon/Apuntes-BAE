### 1. Creación de tablas.
Para crear tablas, empleamos el esqueleto:

```sql
CREATE TABLE IF NOT EXISTS nombre_tabla (
    columna1 tipo_dato(lenght) restricciones,
    columna2 tipo_dato(lenght) restricciones,
    ...
    table_constraints
); 
```
> Empezaremos creando aquellas tablas que no tienen Foreign Key (**restricciones de integridad referencial**).

> PostgreSQL crea por defecto un índice **B-Tree** para cada Clave Primaria. Esto permite que las búsquedas sean logarítmicas en lugar de lineales, optimizando el rendimiento sin que el usuario tenga que configurar nada manualmente.
#### 1.1 Restricciones (constrains).
---
##### 1.1.1 Restricciones a nivel columna.
Posibilidades: NOT NULL, DEFAULT, GENERATED ALWAYS AS IDENTITY, GENERATED BY DEFAULT AS IDENTITY, PRIMARY KEY, UNIQUE, FOREIGN KEY, CHECK (condición),  
> La diferencia entre **GENERATED ALWAYS AS IDENTITY** y **GENERATED BY DEFAULT AS IDENTITY** es que el segundo te permite introducir a mano los ID, mientras que el primero no porque los ID son generados siempre por la BBDD.
---
#### 1.1.2 Restricciones a nivel tabla.
Sirven para definir reglas que abarcan más de una columna o para agrega opciones avanzadas.
* Clave primaria compuesta: 
```sql
CONSTRAINT nombre_pk PRIMARY KEY(col1,col2,...)
```
* Combinación de columnas única:
```sql
CONSTRAINT nombre_uk UNIQUE (col1,col2)
```
* Establecer una relación referencial que puede involucrar varias columnas (FOREIGN KEY):
```sql
CONSTRAINT nombre_fk FOREIGN KEY (col1,col2)
REFERENCES tabla_externa (colA,colB)
```
> La estructura es similar para generar una FK, tener en cuenta que podemos añadir la restricción ON DELETE:

```sql
CONSTRAINT nombre_fk FOREIGN KEY (col1)
REFERENCES tabla_externa (colA) 
ON DELETE [OPCION] --Podemos usar: CASCADE (se borra todo lo que dependa), SET NULL (no se borran los datos que dependen, pero queda el campo vacío), RESTRICT (no deja borrar mientras tenga datos asociados)
```
> Aquí tener en cuenta que en interelaciones recursivas emplearemos **SET NULL**, en tablas intermedias de relaciones N:M nos interesa **CASCADE**, en entidades débiles nos interesa **CASCADE**.
* Verificar una expresión, puede referirse a varias columnas:
```sql
CONSTRAINT nombre_ck CHECK (condición)
```
> La condición puede emplear: BETWEEN, NOT BETWEEN, AND, OR, IN, >, >=
* Definir cuándo se realiza la verificación: *(opcional)*
```sql
CONSTRAINT fk_order DEFERRABLE INITIALLY DEFERRED --Inmediatamente
CONSTRAINT fk_order DEFERRABLE INITIALLY NOT DEFERRED   --Al final de la transacción
```
---
>Ejemplos:
* Ejemplo 1: con restricciones en la tabla
```sql
CREATE TABLE IF NOT EXISTS hotel (
    room_id INT,
    start_time TIMESTAMP,
    end_time TIMESTAMP,
    CONSTRAINT pk_bookings PRIMARY KEY (room_id, start_time),
    CONSTRAINT chk_times CHECK (end_time > start_time)
);
--pk_bookings es una clave primaria compuesta
--chk_times asegura que la hora de fin sea posterior a la de inicio
```
* Ejemplo 2: sin restricciones en la tabla
```sql
CREATE TABLE accounts (
    user_id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(50) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    create_at TIMESTAMP NOT NULL,
    last_login TIMESTAMP
);
```

### 3. Eliminar tabla.
>Para poder usar este comando se debe ser propietario de la tabla o del esquema o superusuario del clúster PostgreSQL.
* Sintáxis básica:
```sql
DROP TABLE [IF EXISTS]nombre_tabla [opción];
```
>Como opción podemos usar: CASCADE (Elimina la tabla y todos los objetos que dependan de ella) O RESTRICT (impide la eliminación si hay objetos que dependan de ella)
* Podemos eliminar varias tablas a la vez:
```sql
DROP TABLE [IF EXISTS] tabla1, tabla2, tabla3 [opción];
```

### 5. Insertar datos.
+ La estructura básica es:
```sql
INSERT INTO nombre_tabla(col1, col2, col3, ...)
VALUES (valor1, valor2,  valor3, ...);
--También podemos insertar varios valores a la vez
INSERT INTO nombre_tabla(col1, col2, ...)
VALUES
(valor1,valor2),
(valor3,valor4);
```
> Dentro de VALUES podemos realizar subconsultas:
```sql
INSERT INTO nombre_tabla (col1, col2) VALUES
(dato1, (SELECT col_objetivo FROM nombre_tabla2 WHERE col_referencia = valor));
```
